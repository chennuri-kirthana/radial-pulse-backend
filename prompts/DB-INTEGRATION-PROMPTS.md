# Connect your EXISTING backend code to the database (schema v15)

Use this file when you already have backend code. (For a brand-new project use `KICKOFF-PROMPTS.md` instead.)

**How to use:** paste ONE prompt into Claude Code, let it finish, do the "✅ Check" yourself, commit, then go to the next.
Use **plan mode** for every step (`claude --permission-mode plan`, or `Shift+Tab` until the status bar shows plan mode).
If a check fails, paste the error back and ask it to fix it. Never paste real passwords or secrets into the chat.

---

## Setup (once, by you)
1. In your backend repo, make a commit (so everything can be undone): `git add -A && git commit -m "before db integration"`.
2. Copy these from this pack into the **root of your backend repo** (don't overwrite your own code):
   `CLAUDE.md` · `db/` · `docs/` · `prompts/` · `.env.example`
   (If your repo already has a `CLAUDE.md`, keep yours and paste this one's content at the end of it.)
3. Put your frontend into `frontend/` (keep `frontend/README.md`).
4. Make sure Docker (for PostgreSQL 16) is installed.
5. `cp .env.example .env` and keep `.env` in `.gitignore`. Fill only local values.
6. Start Claude Code in the repo (`claude`), type `/context` and check that `CLAUDE.md` is listed.
